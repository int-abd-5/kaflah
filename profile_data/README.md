# `kaflah.organisation` public profile data

Collected on 2026-08-14 with the cloned Instaloader repository at version 4.15.3.

Files:

- `profile_summary.json` — normalized public profile fields.
- `posts.json` — normalized metadata for 30 public posts.
- `posts.csv` — the same post index in spreadsheet-friendly form.
- `*.json.xz` — raw compressed Instaloader profile/post metadata.
- `*.txt` — post captions generated by Instaloader.

Related media is in the sibling `../profile_media/` folder and includes the
public profile picture plus the downloaded image/video/carousel files.

The collection used anonymous access and skipped image/video downloads with
`--no-pictures --no-videos --no-profile-pic`. Instagram CDN URLs in raw metadata
may expire.
